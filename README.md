# Excel Assignment 1 – Data Exploration

## Overview

This assignment focuses on exploring and analyzing a product dataset using Microsoft Excel.

The original Raw Dataset was kept unchanged, and the analysis was performed in a separate Assignment 1 worksheet.

## Tasks Completed

1. Explored the raw dataset and created a separate worksheet for the assignment.
2. Used Excel formulas to perform basic data calculations.
3. Used IF() to categorize products into High Price and Standard Price.
4. Calculated the Total Price using SUM().
5. Counted the number of products using COUNT().
6. Calculated the Average Price using AVERAGE().
7. Calculated the Minimum Price using MIN().
8. Calculated the Maximum Price using MAX().
9. Calculated the total price of Electronics products using SUMIF().
10. Counted products below $100 using COUNTIF().
11. Extracted Day, Country Code, and Month from the Product ID using text functions.
12. Kept the original Raw Dataset unchanged and performed the analysis in the Assignment 1 sheet.
